# dylan-bassett-portfolio-site

<h1>ACCESSIBILITY</h1>

Accessibility findings for the site were good, and no major changes were needed to be made.

The site scored 100 in accessibility on Pagespeed Insights

Small changes included:
-
- Preventing the site logo from being keyboard focusable
- Making the CSS hover effects apply to keyboard focus
